# Xin chào, mình là Sơn 👋

Mình đang điều hành **RunAgent Robotics** tại **[runagent.io](https://runagent.io)**, tập trung vào việc xây dựng hạ tầng và sản phẩm cho hệ thống robot quy mô lớn.

## Các dự án mã nguồn mở

### 1) Run Factory

**[Run Factory](https://github.com/runagent-robotics/run-factory)** là nền tảng mã nguồn mở để điều phối, trực quan hóa và mở rộng hàng triệu robot cùng hoạt động trong một nhà máy.

Dự án cung cấp lớp hạ tầng để xây dựng hệ thống robot phân tán quy mô lớn, hỗ trợ:
- Điều phối thời gian thực
- Phân bổ tác vụ thông minh
- Quan sát toàn hệ thống qua mô phỏng digital twin

### 2) Pavo Engine

**[Pavo Engine](https://github.com/sonnhfit/pavo-engine-py)** là AI agent chỉnh sửa video tự động.

Thông qua prompt ngôn ngữ tự nhiên, Pavo Engine có thể tạo video được biên tập chuyên nghiệp nhờ kiến trúc module 4 lớp, kết hợp:
- Computer Vision
- Speech Processing
- Timeline Automation

Tính năng nổi bật:
- **JSON to Video**
- Python
- MIT License
- FFmpeg
