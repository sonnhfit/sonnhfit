## Open Source Projects

### 1) Run Factory

**[Run Factory](https://github.com/runagent-robotics/run-factory)** is an open-source platform for orchestrating, visualizing, and scaling millions of robots working together in a factory.

It provides the infrastructure layer for building large-scale, distributed robotic systems, enabling:
- Real-time coordination
- Intelligent task allocation
- Full-system visibility through digital twin simulation

### 2) Pavo Engine

**[Pavo Engine](https://github.com/sonnhfit/pavo-engine-py)** is an AI-powered agent for automated video editing.

Using natural language prompts, Pavo Engine produces professionally edited videos through a modular 4-layer architecture that combines:
- Computer Vision
- Speech Processing
- Timeline Automation

Key features:
- **JSON to Video**
- Python
- MIT License
- FFmpeg
